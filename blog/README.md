# Blog

Long-form posts from Eric Thomas on the Dagster community components registry — design essays, component tours, honest retrospectives.

## RSS feed

Subscribe: [`blog/feed.xml`](https://raw.githubusercontent.com/eric-thomas-dagster/dagster-community-components-cli/main/blog/feed.xml)

The feed + the Posts table below are auto-regenerated by the
[`blog` GitHub Action](../.github/workflows/blog.yml) whenever a post
is added or changed. To run the generator locally:

```bash
python tools/generate_rss.py            # regen feed.xml + README Posts table
python tools/generate_rss.py --check    # exit 1 if either is stale (for CI)
```

## Writing a new post

1. Create `blog/<slug>.md` starting with YAML frontmatter:

```yaml
---
title: "Your post title"
date: 2026-08-20
author: Eric Thomas
description: "One-sentence summary — appears in RSS + link previews + the Posts table row."
---
```

2. Commit + push. That's it — the `blog` GitHub Action regenerates
   `blog/feed.xml` + the **Posts** table above and commits the result
   back on your behalf.

If you'd rather run it locally (skips the auto-commit round-trip):

```bash
python tools/generate_rss.py            # regen feed.xml + README table
git add blog/ && git commit && git push
```
