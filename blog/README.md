# Blog

Long-form posts from Eric Thomas on the Dagster community components registry — design essays, component tours, honest retrospectives.

## RSS feed

Subscribe: [`blog/feed.xml`](https://raw.githubusercontent.com/eric-thomas-dagster/dagster-community-components-cli/main/blog/feed.xml)

The feed is regenerated by [`tools/generate_rss.py`](../tools/generate_rss.py) — run after adding a new post:

```bash
python tools/generate_rss.py            # regenerate blog/feed.xml
python tools/generate_rss.py --check    # exit 1 if stale (for CI)
```

## Writing a new post

1. Create `blog/<slug>.md` starting with YAML frontmatter:

```yaml
---
title: "Your post title"
date: 2026-08-20
author: Eric Thomas
description: "One-sentence summary that shows up in RSS + link previews."
---
```

2. Add a row to the **Posts** table above.
3. Regenerate the feed: `python tools/generate_rss.py`
4. Commit `blog/<slug>.md`, `blog/README.md`, `blog/feed.xml`.
