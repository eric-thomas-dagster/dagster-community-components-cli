# Registry resources in dagster-community-components 0.10.194: call reference for the converter

Read from `component.py` and `schema.json` of 0.10.194 (signatures printed from the installed classes), with the offline runs noted in `component-wishlist.md`. Each resource is registered by a component with `type: dagster_community_components.<Component class>` and `attributes: {resource_key: <key>, ...}`; an asset reads it as a `ConfigurableResource` parameter or `context.resources.<resource_key>`. Environment variable fields hold the variable's name, never the value (the resource resolves it with `dg.EnvVar`, so a required name that is unset fails config resolution when a run starts). "Gap" is what the converter still has to do in plain Python.

| Operator family | Resource id (component class) | Methods to call (exact signatures) | Config fields and required env vars | Gap |
